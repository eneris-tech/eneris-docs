# Invoicing and Pricing Items

**Invoicing** in Eneris allows you to create professional invoices for your inspection services directly from within an Inspection. Combined with **Pricing Items**, you can build a reusable library of your common services and fees, making invoice creation fast and consistent.

The invoicing workflow is simple:

1. Set up your **Pricing Items** once (your service catalog)
2. Create an **Invoice** from any inspection
3. Add line items from your pricing library or create custom items
4. Share the invoice via email or download as PDF
5. Track payment status

:::info

Pricing Items are reusable across all your invoices. Set them up once and add them to any invoice with a single tap.

:::

## Pricing Items

### What are Pricing Items?

**Pricing Items** are reusable service entries that you can quickly add to invoices. Each pricing item includes:

- **Name** — A description of the service (e.g., "Home Inspection - Standard")
- **Price per unit** — The price per unit
- **Tax Rate** — The applicable tax percentage

By maintaining a library of pricing items, you ensure consistent pricing across all your invoices and save time during invoice creation.

### View Pricing Items

To view your existing **Pricing Items**:

1. Select the hamburger menu in the upper left within the app.
2. Select `Invoicing`.

You will see a list of all your saved pricing items with their names and prices.

<img src={ImageInvoicing1} style={{ maxWidth: '250px', width: '100%' }} alt="View pricing items." />

### Create a Pricing Item

To create a new **Pricing Item**:

1. Navigate to `Invoicing` from the hamburger menu.
2. Select `Create new pricing item`.
3. Enter a **Name** for the item (e.g., "Radon Testing").
4. Enter the **Price per unit**.
5. Optionally, set a **Tax rate** percentage.
6. Select `Create`.

<img src={ImageInvoicing2} style={{ maxWidth: '250px', width: '100%' }} alt="Create a pricing item." />

:::tip

Create pricing items for all your common services before you start invoicing. This makes creating invoices much faster.

:::

### Edit a Pricing Item

To modify an existing **Pricing Item**:

1. Navigate to `Invoicing` from the hamburger menu.
2. Select the item you wish to edit.
3. Update the **Name**, **Price per unit**, and/or **Tax rate** as needed.
4. Select `Save changes`.

:::info

Changes to a **Pricing Item** only affect **new invoices**. Existing invoices retain the pricing that was set when they were created.

:::

### Delete a Pricing Item

To delete a **Pricing Item**:

1. Navigate to `Invoicing` from the hamburger menu.
2. Select the item you wish to delete.
3. Scroll to the bottom and select `Delete pricing item`.
4. Confirm the deletion when prompted.

:::warning

Deleting a **Pricing Item** cannot be undone. Existing invoices using this item will retain their line item data.

:::

## Creating an Invoice

### Create Invoice from Inspection

Invoices are created within an [**Inspection**](/docs/concepts/inspections). To create an invoice:

1. Open the Inspection you want to invoice.
2. Navigate to the **Invoice** section.
3. Select the edit icon.
4. [Add line items](/docs/concepts/invoicing-and-pricing-items#adding-line-items).
5. Optionally, add a **Memo** for additional notes.
6. Select `Create invoice`.

<img src={ImageInvoicing3} style={{ maxWidth: '250px', width: '100%' }} alt="Creating an invoice within an Inspection." />

:::info

The system automatically generates an invoice number in the format `INV-YYYY-NNNNN` (e.g., INV-2026-00001).

:::

### Adding Line Items

You can add line items to your invoice in two ways:

**From Pricing Library:**
1. Select `+ Pricing item`.
2. Choose one or more items from your pricing library.
3. [Adjust the quantity](/docs/concepts/invoicing-and-pricing-items#adjusting-pricing-item-quantity) if needed.

**Custom Item:**
1. Select `+ Custom`.
2. Enter the item **Name**.
3. Enter the **Price per unit**.
4. Set the **Quantity**.
5. Optionally, set a **Tax rate**.

<img src={ImageInvoicing4} style={{ maxWidth: '250px', width: '100%' }} alt="Creating a Pricing Item within an inspection." />

### Adjusting Pricing Item Quantity

When creating an Inspection invoice you can update the quantity of a line item. To update the quanity:

1. Select the pricing item you added.
2. Update the `Quantity`.
3. Select `Save changes`.

<img src={ImageInvoicing5} style={{ maxWidth: '250px', width: '100%' }} alt="Adjusting Pricing Item quantity." />

### Automatic Calculations

Eneris automatically calculates all invoice totals:

- **Line Total** — Price per unit × quantity for each item
- **Line Tax** — Line total × tax rate for each item
- **Subtotal** — Sum of all line totals
- **Tax** — Sum of all line taxes
- **Total** — Subtotal + tax total

<img src={ImageInvoicing6} style={{ maxWidth: '250px', width: '100%' }} alt="Invoice subtotals, tax totals, and overall total amounts." />

:::info

All calculations update in real-time as you add or modify line items.

:::

## Payment Tracking

### Invoice Status

Each invoice has a payment status:

- **Unpaid** — Invoice has been created but payment has not been recorded
- **Paid** — Payment has been recorded for this invoice

The status is displayed as a badge on the invoice, making it easy to track outstanding payments.

### Recording Payment

To record a payment on an invoice:

1. Open the invoice.
2. Change the **Invoice Status** to **Paid**.
3. Select a **Payment Method**:
   - Cash
   - Check
   - Debit Card
   - Credit Card
   - Bank Transfer
   - Peer-to-Peer
   - Other (enter a custom description)
4. Set the **Paid Date**.
5. Select `Save changes`.

<img src={ImageInvoicing7} style={{ maxWidth: '250px', width: '100%' }} alt="Recording a payment on an Invoice." />

## Invoice Actions

### Download PDF

To download an invoice as a PDF:

1. Navigate into the Inspection.
2. Locate the Invoice section.
3. Select the **Download PDF** icon.
4. Download the PDF on your device.

The PDF includes your business information, invoice details, line items with calculations, and any memo you added.

<img src={ImageInvoicing8} style={{ maxWidth: '250px', width: '100%' }} alt="Generate and download the Invoice PDF." />

### Share via Email

To share an invoice with your client via email:

1. Navigate into the Inspection.
2. Locate the Invoice section.
3. Select the **Email** icon.
3. The email recipients are auto-populated from the Inspection contacts.
4. Adjust the **To**, **Cc**, and **Bcc** fields as needed.
5. Select `Send`.

<img src={ImageInvoicing9} style={{ maxWidth: '250px', width: '100%' }} alt="Share the invoice via email." />

The email includes a link to view the invoice online, along with a PDF attachment.

:::warning

Anyone with access to the public invoice link will be able to view the invoice. Only share invoice links with intended recipients.

:::
