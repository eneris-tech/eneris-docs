# SOP Templates

**SOP Templates** (Standards of Practice Templates) allow you to attach professional standards documentation to your inspection reports. By linking an SOP to your [**Form Templates**](/docs/concepts/form-templates), you can ensure every inspection report includes the relevant standards your work adheres to.

SOPs are critical for:

- **Professional credibility** — Demonstrating adherence to industry standards builds trust with clients.
- **Compliance** — Many inspection associations require members to follow specific standards.
- **Consistency** — Ensuring all inspections reference the same standards across your team.

:::info

SOP Templates are reusable across multiple [**Form Templates**](/docs/concepts/form-templates). Set them up once and apply them to any template you create.

:::

## What is a Standard of Practice (SOP)?

A **Standard of Practice (SOP)** is a document that defines the minimum requirements for conducting inspections. These standards outline what inspectors should and should not inspect, limitations, and the scope of the inspection. SOPs are often published by professional inspection associations, but individual inspectors and multi-inspector organizations can also create their own.

Including the SOP in your reports helps clients understand what was covered and sets appropriate expectations for the inspection scope.

## Managing SOP Templates

### View SOP Templates

To view your existing **SOP Templates**:

1. Select **SOP templates** from the sidebar.

<img src={ImageSOPTemplates1} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="SOP Templates menu in sidebar." />

You will see a list of all available SOP Templates, including the default templates and any custom templates you have created.

<img src={ImageSOPTemplates2} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="List of SOP templates." />

### Create an SOP Template

To create a new **SOP Template**:

1. Select **SOP templates** from the sidebar.
2. Select **Create new SOP template**.
3. Choose between **Create new** or **Duplicate existing** using the segmented control at the top.
4. If creating new, select a template to start from (e.g., Blank, InterNACHI, ASHI, etc.) or start from scratch.
5. Enter a **Standards of Practice template name** and select **Create new**.
6. Enter a **Name** for your template (this is for internal reference only).
7. Enter a **Title** (this appears in your PDF reports).
8. Optionally, enter a **Link** to the full SOP document online.
9. Enter the SOP content in the **Body** field.
10. Select **Save changes** at the bottom of the page.

<img src={ImageSOPTemplates3} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Create new SOP template form." />

:::info

The **Name** field is used to identify the template in your list. The **Title** field is what appears in your client-facing PDF reports.

:::

### Edit an SOP Template

To modify an existing **SOP Template**:

1. Select **SOP templates** from the sidebar.
2. Select the template you wish to edit.
3. Update the **Name**, **Title**, **Link**, and **Body** fields as needed.
4. Select **Save changes**.

:::info

Changes to an **SOP Template** only affect new [**Inspections**](/docs/concepts/inspections) created after the change. Existing inspections retain the SOP content that was embedded when they were created.

:::

<img src={ImageSOPTemplates4} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Edit SOP template showing title, URL, and body fields." />

### Delete an SOP Template

To delete an **SOP Template**:

1. Select **SOP templates** from the sidebar.
2. Select the template you wish to delete.
3. Scroll to the bottom and select **Delete SOP Template**.
4. Confirm the deletion when prompted.

:::warning

Deleting an SOP Template cannot be undone. Existing inspections that use this template will retain their embedded SOP content.

:::

## Linking SOP to Form Templates

To associate an **SOP Template** with a [**Form Template**](/docs/concepts/form-templates):

1. Select **Form templates** from the sidebar.
2. Select the **Form Template** you wish to modify.
3. Locate the **Standards of practice template** field.
4. Select the edit icon and choose the desired **SOP template** from the menu.
5. Select **Save** in the upper right.

<img src={ImageSOPTemplates5} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Linking SOP template to a Form Template." />

:::info

Once linked, the SOP is automatically embedded when creating new [**Inspections**](/docs/concepts/inspections) using that **Form Template**. The SOP content (title, link, and body) is copied into the Inspection Form, allowing for per-inspection modifications if needed.

:::

## SOP in Inspection Forms

When you create an [**Inspection**](/docs/concepts/inspections) using a **Form Template** that has an SOP linked, the SOP content is automatically embedded into the [**Inspection Form**](/docs/concepts/inspection-forms).

You can view and modify the embedded SOP content directly within the Inspection if you need to make ad-hoc changes for a specific job. This is useful when:

- A client requests additional scope clarifications
- You need to add project-specific limitations
- You want to reference a different version of the standards

Changes made to the SOP within an **Inspection Form** only affect that specific Inspection — they do not update the original **SOP Template**.

<img src={ImageSOPTemplates6} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="SOP section in an inspection form." />

## SOP in Reports

When you [publish a report](/docs/concepts/reports#publishing-a-report), the SOP content appears in the PDF report. The SOP section includes:

- **Title** — The display title (e.g., "Standards of Practice")
- **Link** — A link to the full SOP document (if provided)
- **Body** — The SOP content body text (if provided)

:::tip

Including your SOP in reports demonstrates compliance with professional standards and helps set clear expectations with your clients about the scope and limitations of the inspection.

:::

:::info

To attach other supporting documents such as diagrams, code excerpts, or homeowner checklists, use [**Reference Files**](/docs/concepts/reference-files). Unlike SOPs, which are linked to a **Form Template**, reference files are attached to an individual **Inspection Form** as [**appendices**](/docs/concepts/inspection-forms#appendices).

:::
