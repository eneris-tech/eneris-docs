# Customizing Form Templates

You can customize [**Form Templates**](/docs/concepts/form-templates) to include the exact categories, components, fields, and field options you need for any type of inspection. Once saved, your customized **Form Templates** are available for reuse across multiple inspections, saving time and improving report consistency.

:::info

See the [**Inspection Form** framework](/docs/concepts/inspection-forms#inspection-form-framework) documentation for a detailed explanation on categories, components, fields, and field options.

:::

## Types of customizations

Customizations include:

- **Custom categories** – Group components however you want.
- **Custom components** – Add new inspection items or rename existing ones.
- **Custom fields** – Create new fields.
- **Custom field options** – Add or edit the field options.
- **Required/Optional fields** – Choose which fields must be filled out.
- **Visibility** – Hide fields from the final report.
- **Edit field names** – Rename fields to suit your wording.
- **Edit field options** – Change placeholder or default text for clarity.
- **Edit disclaimers and limitations** – Change placeholder or default text for clarity.

You have full control over how your **Form Templates** look and behave — without needing to code.

:::tip

You can reorder categories, components, and fields to match your inspection workflow. On mobile, press and hold an item and drag it. On the web app, select `Reorder`, drag the items into the order you want, then select `Done`.

:::

:::tip

You don't have to make every customization in the **Form Template** itself. If you change an [**Inspection Form**](/docs/concepts/inspection-forms) during an inspection, the **Refine form template** feature lets you review those changes afterwards and merge the ones you want back into the template. See [Applying Inspection Form changes to the Form Template](/docs/concepts/form-templates#applying-inspection-form-changes-to-the-form-template).

:::

## Creating, editing, and deleting categories

The sections below cover creating, editing, and deleting **categories**.

### Creating categories

To create new categories:

1. Open the **Form Template** you would like to edit.
2. Select `Edit` in the **Inspection categories** section to open the **Edit inspection categories** page.
3. Select `New category` to open the **Add new category** sheet.
4. Choose `Create blank category` or `Create from existing category`.
5. Enter a `category name` and select a `category icon`.
6. Select `Create new category`.

<img src={ImageCustomizingFormTemplates1} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Creating new categories in a Form Template." />

:::tip

- `Create blank category` means there are no components within the new category.
- `Create from existing category` means you can select an existing category and duplicate all of the components, fields, and field options within as a starting point. You can then further customize this duplicated category to suit your needs.

:::

### Editing categories

To edit existing categories:

1. Open the **Form Template** you would like to edit.
2. Select `Edit` in the **Inspection categories** section.

<img src={ImageCustomizingFormTemplates2} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Edit icon in the Categories section of a Form Template." />

3. Select the edit icon next to the category you would like to edit.
4. Edit the `category name` and `category icon` as desired.
5. Select `Save`.

<img src={ImageCustomizingFormTemplates3} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Editing categories in a Form Template." />

### Deleting categories

To delete existing categories:

1. Select `Edit` in the **Inspection categories** section.
2. Select the edit icon next to the category you would like to delete.
3. Select the `Delete` button.

<img src={ImageCustomizingFormTemplates4} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Deleting categories in a Form Template." />

## Creating, editing, and deleting components

The sections below cover creating, editing, and deleting **components**.

### Creating components

To create new components:

1. Enter the category in which the new component should be created.
2. Select `Edit components`.

<img src={ImageCustomizingFormTemplates5} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Edit components button in the category details page." />

3. Select `New component` to open the **Add new component** sheet.
4. Choose `Create blank component` or `Create from existing component`.
5. Enter the new component name.
6. Select `Create new component`.
7. The new component has been successfully created and can be located at the bottom of the component list.

<img src={ImageCustomizingFormTemplates7} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Creating new components in a Form Template." />

:::tip

- `Create blank component` means there are no fields within the new component.
- `Create from existing component` means you can select an existing component and duplicate all of the fields and field options within as a starting point. You can then further customize this duplicated component to suit your needs.

:::

### Editing components

To edit existing components:

1. Enter the category containing the component you would like to edit.
2. Select `Edit components`.
3. Select the pencil icon next to the component you would like to edit.

<img src={ImageCustomizingFormTemplates6} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Pencil icon next to a component in the edit components page." />

4. Update the `Component name` at the top of the page.

<img src={ImageCustomizingFormTemplates8} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Editing the component name in a Form Template." />

### Deleting components

To delete existing components:

1. Enter the category in which the component should be deleted.
2. Select `Edit components`.
3. Locate the component you would like to delete and select the trash icon next to it.
4. Confirm the deletion when prompted.

<img src={ImageCustomizingFormTemplates9} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Trash icon next to a component in the edit components page." />

## Creating, editing, and deleting fields

The sections below cover creating, editing, and deleting **fields**.

### Creating fields

To create new fields:

1. Enter the category containing the component where the new field should be created.
2. Select `Edit components`.
3. Select the pencil icon next to the component where the new field should be created.
4. Select `New field` to open the **Add new field** sheet.
5. Choose `Create blank field` or `Create from existing field`.
6. Enter a `field name` and select the [`field type`](/docs/concepts/customizing-form-templates#field-types).
7. Select `Create new field`.
8. The new field has been successfully created and can be located at the bottom of the field list.

<img src={ImageCustomizingFormTemplates10} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Creating new fields in a Form Template." />

:::tip

- `Create blank field` starts a new field from scratch using the `field type` you select.
- `Create from existing field` lets you duplicate a field (and its options) from another category and component as a starting point. The field type is inherited from the source field.

:::

### Field types

You can use different types of fields in your **Form Templates**:

- **Checkbox** – Creates checkboxes for you to select one or more options.
- **Choice** – Creates radio buttons for you to select a single option.
- **Text** – For short text descriptions (80 characters max per option).
- **Multi-line text** – For longer text descriptions (1,000 characters max per option).
- **Media** – For capturing photos and videos with saved captions.
- **Reference images** – For attaching illustrative images from your team's [**Reference Files**](/docs/concepts/reference-files) library or from your device. See [Reference images fields](#reference-images-fields).


<img src={ImageFieldTypeReferenceImages} style={{ maxWidth: '800px', width: '100%' }} alt="The Field type list showing Checkbox, Choice, Text, Multi-line text, Media, and Reference images, with Reference images highlighted." />

Each field type lets you capture different types of data for better clarity in your reports.

:::info

You can create many fields of the same field type in an individual component.

:::

#### Reference images fields

A **Reference images** field holds illustrative pictures rather than pictures you take on site. It's the right field for a diagram of correct flashing detail, a manufacturer's data plate chart, or a photo of what a properly installed component should look like, the kind of image that helps a client understand a finding but is the same on every job.

It differs from a **Media** field in where the pictures come from. A **Media** field is filled with photos and videos you capture during the inspection. A **Reference images** field is filled from two sources:

- **Reference file library** — insert diagrams and illustrations from your [**Reference Files**](/docs/concepts/reference-files) library, so everyone on the team uses the same image
- **Upload directly** — insert a one-off image from your device that isn't in the library
<img src={ImageReferenceImagesSources} style={{ maxWidth: '800px', width: '100%' }} alt="The Add reference image menu offering Reference file library and Upload directly." />



<img src={ImageReferenceImagesField} style={{ maxWidth: '800px', width: '100%' }} alt="A Reference images field holding one attached diagram with its caption, alongside an Add image tile." />

Attached images appear as a tile grid with a short caption beneath each. Selecting a tile opens it larger, where you can write or edit its caption and remove it from the field.

:::info

A **Reference images** field holds up to **5** images, and each caption can be up to **500** characters.

Captions here are free text you write per image, unlike a **Media** field, where captions are chosen from a saved list of options.

:::

:::info

Picking from the team library requires a connection, because the library lives in the cloud. Uploading from your device works offline and syncs later, like any other photo.

:::

When you attach an image from the library, Eneris takes a copy of the picture and its caption at that moment. Changing the original in the library afterwards does not alter forms that already use it, so a template you built last season keeps rendering the image it was built with.

## Additional field settings

In addition to the field name and field type there are a number of settings to help you customize your **Form Template**.

### Field requirement

A field can be toggled as `required` or `optional`.

- **Required** — When selected, the component list page will provide a visual indicator. This helps you quickly assess whether any component inspection was missed.
    - When all required fields within a component are completed, the visual indicator will automatically update to a green checkmark.
- **Optional** — When selected, the field is optional in your inspection.
    - By default, all fields are set as optional.

The field requirement toggle helps ensure required components and their fields are completed in a consistent manner. This is used to track your overall completion of the inspection in the [Progress checklist](/docs/concepts/inspection-forms#progress-checklist).

:::info

In templates created by Eneris, the fields that are required are based on the relevant association's Standards of Practice.

:::

### Field visibility

A field's visibility controls whether it appears inside the inspection form, on the final report, or both. There are up to four settings depending on whether you're editing a field at the [shared field](/docs/concepts/inspection-forms#shared-fields) level or inside a specific component:

- **Show** — The field appears in the inspection form and in the final report.
    - By default, all fields are set to **Show**.
- **Hide** — The field still appears inside the inspection form, but is excluded from the final report. Entries remain visible to you and your team within the [Inspection](/docs/concepts/inspections).
    - Useful for internal notes, personal reminders, or photo proof that you don't want to share with clients.
    - e.g., Your **Form Template** includes two hidden fields in the Garage Doors component: a checklist to confirm the garage door is closed after inspection, and a media field for photo proof. Both are captured during inspection but never appear in the client report.
- **Disabled** — The field is hidden in **both** the inspection form and the final report.
    - Use this to turn a field off entirely without deleting it. This is the only way to remove the five fields that cannot be deleted (`Status`, `Photos & Videos`, `Condition`, `Recommended Action`, `Summary Label`) from your workflow.
    - e.g., You don't use the `Recommended Action` field in your process. Setting it to **Disabled** at the template level removes it from every component in the form and from the report.
- **Default** — Only available when editing a shared field from inside a specific component. The field uses the visibility setting defined in the shared field.

### Favorite options

Both **text** and **multi-line text** field types allow you to select up to 10 favorite field options from the [option library](/docs/concepts/customizing-form-templates#option-library).

- **Text fields** — When a field option is selected as a favorite, it will appear next to the `Add New` button for easy selection when inspecting the component.
    - Add favorites by selecting the `+` icon next to the field option in the option library.
- **Multi-line text fields** — When a field option is selected as a favorite, it will appear below the text box when you select `Add new text` in the field entry.
    - Add favorites by selecting the `+ Add` icon next to the field option in the option library.

### Option library

A list of all saved responses for the field.

## Category limitations

In addition to [general limitations](/docs/concepts/inspection-forms#general-limitations), you may also add **category limitations**.

- After entering a category, the top menu bar will have an option for `Limitations`. Enter any category-specific inspection limitations here.
    - e.g., If you are inspecting a roof and part of it is covered in solar panels you may wish to enter that limitation here.
