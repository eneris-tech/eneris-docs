# Form Templates

**Form Templates** allow for the customization of inspection lists and the pre-filling of report fields. Once saved, they are available for selection when creating a new [**Inspection**](/docs/concepts/inspections), and when adding a new [**Inspection Form**](/docs/concepts/inspection-forms) to an existing **Inspection**.

Templates are critical to an efficient inspection workflow on-site. Eneris allows for easy customization of templates and includes the most commonly used templates in US and Canadian markets to help you get started quickly.

:::info

If there is a template you would like to see, [we would love to hear about it](/docs/support/contact-support).

:::

**Form templates** allow you to:

- Customize what categories (e.g. Roof, Plumbing, HVAC) and components (e.g. Roof Coverings, Water Heater, Heating System) are included.
- Define the **Shared Fields** that appear within each component (e.g., Perhaps you would like the *Description*, *Condition*, *Risk*, and *Recommend Action* fields to appear in every component).
- Define component specific fields (e.g., Only the `Heating Systems` component would have the *Heating Energy Source*, *Heating System Type*, and *Heating System Brand* fields).
- Set up **field options** so your responses are consistent, fast, and standardized.
- Select default entries (e.g., General limitation statements may be the same for every inspection).

How you setup and use **Form Templates** is completely up to you.

- You can stick to using our default templates.
- You can create a master template for use in all your inspections.
- You can create templates for specific property types (e.g., If you inspect a lot of apartments you may want to create a new template that does not include components like `Fireplace` or `Gutters` as they would not be relevant).

:::tip

Once created, **Form Templates** can be reused across multiple inspections, saving time and improving report consistency.

:::

## Default Form Templates

The following default **Form Templates** are available in Eneris:

### General

- Eneris template
    - A custom template developed by Eneris that incorporates the best parts of the ASHI, InterNACHI, CAHPI, HIABC, and ASTTBC inspection templates.

### Associations

- American Society of Home Inspectors (ASHI) template
- International Association of Certified Home Inspectors (InterNACHI) template
- Home Inspectors Association BC (HIABC) template
- Applied Science Technologists & Technicians of BC (ASTTBC) template
- American Home Inspectors Training (AHIT) template
- Canadian Association of Home & Property Inspectors (CAHPI) template

## Review default Form Templates

Follow these steps to review the default **Form Templates**:

1. Select `Form templates` from the sidebar.

2. Select `Create new template`.
3. Select the template you are interested in (or create a `Blank Template`).

<img src={ImageFormTemplates2} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Select a base template for your new Form Template." />

4. Enter a name for your new template.
5. Select `Create new`.
6. Select the new **Form Template** you just created and explore the various inspection categories.

<img src={ImageFormTemplates4} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Form Template details page showing inspection categories." />

:::info

As seen above, Eneris includes a wide range of ready to use inspection templates. These templates were created after careful consideration of the Standards of Practice (SOP) for various regions.

- **Eneris Template** blends required items from major inspection associations in North America to produce a coherent template with great coverage on the most common subjects encountered during an inspection.
- **ASHI Template** corresponds to the [American Society of Home Inspectors SOP](/pdfs/ASHI-Standards-of-Practice-2015.pdf).
- **InterNACHI** **Template** corresponds to the [International Association of Certified Home Inspectors SOP](/pdfs/InterNACHI-Standards-of-Practice-2018.pdf).
- **AHIT Template** corresponds to paper forms that were traditionally used by inspectors trained by AHIT.
- [**HIABC**](/pdfs/HIABC-Standards-of-Practice-2016.pdf) and [**ASTTBC**](/pdfs/ASTTBC-Standards-of-Practice-2016.pdf) **Templates** correspond to their respective associations in the province of British Columbia, Canada.
- **CAHPI Template** corresponds to the [Canadian Association of Home & Property Inspectors SOP](/pdfs/CAHPI-Standards-of-Practice-2023.pdf).

You can also attach [**SOP Templates**](/docs/concepts/sop-templates) to your **Form Templates** to include Standards of Practice documentation in your inspection reports.

:::

## Creating a Form Template

To create a new **Form Template**:

1. Select `Form templates` from the sidebar.
2. Select `Create new template`.

<img src={ImageFormTemplates1} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Form Templates page with sidebar navigation." />

3. If you would like to create your new template using an existing template as a baseline select one from the list. Otherwise, scroll to the bottom of the list and select `Blank Template` to start with a clean slate.

<img src={ImageFormTemplates2} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Select a base template for your new Form Template." />

4. Enter a name for your new template.
5. Select `Create new`.

<img src={ImageFormTemplates3} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Enter a name and create your new Form Template." />

6. Edit your new template, as desired.

:::info

You can always edit the **Form Template** at any time.
- Changes to a **Form Template** are only reflected on any **new** inspection that is created after the template change.

:::

## Selecting a Form Template

There are two ways to add a **Form Template** to an inspection.

### Adding a Form Template when Creating a New Inspection

When creating a new inspection you must select a **Form Template:**

1. Begin [creating a new **Inspection**](/docs/concepts/inspections#create-an-inspection).
2. Select the `Form Template` dropdown.
3. Select the desired **Form Template**.

<img src={ImageFormTemplates5} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Select a Form Template when creating a new Inspection." />

4. Select `Create inspection`.
5. The **Form Template** is now loaded into the inspection, ready for use.

### Adding a Form Template to an Existing Inspection

1. Open the **Inspection** you wish to add a new **Form Template** to.
2. Navigate to the **Inspection Forms** section.
3. Select `Add new`.

<img src={ImageFormTemplates6} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="Inspection detail page showing the Add new button for adding Form Templates." />

4. Select the desired **Form Template**.
5. The **Form Template** has been successfully loaded as an **Inspection Form** in the **Inspection**.

:::info

Reminder: Each [**Inspection**](/docs/concepts/inspections) can have one or more [**Inspection Forms**](/docs/concepts/inspection-forms) associated with it. **Inspection Forms** allow you to associate different types of inspections with a single inspection site visit.

:::

## Supplementary Forms

**Supplementary forms** are specialized insurance forms that you complete alongside your main inspection and deliver as a separate, compliant PDF. Eneris includes two ready-to-use supplementary form templates for the Florida market:

- **4-Point Inspection**: the Florida 4-Point inspection form (Insp4pt 03 25), covering the four systems insurers care about most: roof, electrical, HVAC, and plumbing.
- **Uniform Mitigation Verification Inspection**: the Florida wind mitigation form (2026 OIR-B1-1802), documenting the features that protect a home against wind damage.

Both are kept up to date with the latest official forms, and each generates a filled, flattened, insurer-ready PDF when you publish.

:::info

Supplementary forms are designed for Florida insurance inspections and follow the official Florida OIR forms. They produce a PDF only (no web or summary report). The form fields, sections, and layout are fixed to stay compliant, so these templates are used as-is rather than customized like a standard **Form Template**.

:::

<img src={ImageSupplementary1} style={{ maxWidth: '800px', width: '100%' }} width={1280} height={800} alt="The Create from list showing the 4-Point Inspection and Uniform Mitigation Verification Inspection options." />

### Adding a supplementary form

You add a supplementary form the same way you add any other template, by first creating it from the built-in template and then adding it to an inspection:

1. Select `Form templates` from the sidebar.
2. Select `Create new form template`.
3. With `Create new` selected, scroll the `Create from` list and choose **4-Point Inspection** or **Uniform Mitigation Verification Inspection**.
4. Enter a `Name` for the template and select `Create new`.
5. Add the template to an inspection, either when [creating a new **Inspection**](/docs/concepts/inspections#create-an-inspection) or by adding it to an existing one (see [**Selecting a Form Template**](#selecting-a-form-template) above).

:::tip

Inspectors typically complete the main home inspection first, then create the 4-Point or wind mitigation form for the same property. Adding the supplementary form to the **same Inspection** lets Eneris carry over the property and client details for you.

:::

### Auto-populated details

When you add a supplementary form to an inspection, Eneris pre-fills the form from the inspection so you don't have to re-type information you already captured. Depending on the form, this includes:

- Owner / client name
- Property address, city, and ZIP code
- Phone number and email
- Year built and number of stories
- Inspection date

Every pre-filled value remains editable, so you can review and adjust anything before publishing. The form is split into the same sections as the official document, for example **Inspection Details**, **Electrical**, **HVAC**, **Plumbing**, and **Roof** on the 4-Point form.

### Photos and signature

Photos you attach to a supplementary form are automatically organized **by section** (for example, Electrical, HVAC, Plumbing, and Roof) and laid out on dedicated photo pages in the generated PDF, each with a caption. Your [**inspector profile**](/docs/concepts/inspector-profiles) signature is embedded on the form automatically, so the published PDF is ready to send.

### Publishing and sharing

Publish a supplementary form just like any other [**report**](/docs/concepts/reports). On publish, Eneris fills the official form, merges in any photo pages, and produces a single compliant PDF.
