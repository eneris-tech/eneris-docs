# Inspector Profiles

**Inspector Profiles** let you associate specific business or certification information with an inspection. They’re useful if:

- You own **multiple businesses** and want to brand each inspection accordingly.
- You hold **multiple types of certifications or licenses** and need to display the correct details on the report.

You can create as many profiles needed and then choose the one that best fits each inspection.

## Creating an Inspector Profile

To create a new **Inspector Profile**:

1. Navigate to the home page
2. Select `Inspector profiles`

    <img src={ImageInspectionProfiles1} style={{ maxWidth: '250px', width: '100%' }} alt="Inspector profiles home page." />

3. Select `Create new profile`
4. Enter the relevant details:
    - Profile name (*required*)
        - For you to identify what profile this is. Does not show up on reports.
    - Primary inspector (*required*)
        - Auto-populated based on your Eneris account details.
    - Business name
    - Website
    - Phone number
    - Business address
    - Business logo
    - Business portrait
        - An image of yourself.
    - Professional associations
        - If you belong to any professional associations you may enter them here. Include your member/certification number, as desired.
5. Select `Create Profile` at the bottom of the page

Your **Inspector Profile** is now available to assign to inspections.

## Selecting an Inspector Profile

To apply an **Inspector Profile** to an inspection:

1. Begin creating an **Inspection** [link to [create an inspection](https://www.notion.so/Inspections-226d9f0aeb5a8068b23fe5f466d0b8a8?pvs=21)]
2. Navigate to the `Configuration` section
3. Select the Inspector `Profile` dropdown menu and choose the desired profile

### Updating the **Inspector Profile** for existing Inspections

You may also update the **Inspector Profile** for existing **Inspections**:

1. Select the relevant **Inspection**
2. Navigate to the `Inspector Profile` section
3. Select the edit icon

    <img src={ImageInspectionProfiles2} style={{ maxWidth: '250px', width: '100%' }} alt="Editing inspector profile in inspection." />

4. Choose the desired profile

    <img src={ImageInspectionProfiles3} style={{ maxWidth: '250px', width: '100%' }} alt="Selecting desired inspector profile." />

:::info

To show the latest **Inspector Profile** changes in your reports, you must republish the report. [link to [republish report](https://www.notion.so/Reports-226d9f0aeb5a80de843ef4dd0f700533?pvs=21)]

:::

The selected profile’s information will appear on the PDF report’s cover page—ensuring it reflects the correct credentials or business branding.
